# Data

The notebook expects two files in this folder:

- `Train.csv`: 20,000 rows of sensor readings (`V1` to `V40`) with the target column.
- `Test.csv`: 5,000 rows with the same columns, used only for the final evaluation.

Both files contain some missing values, which the notebook imputes inside its modeling pipeline.

The datasets were provided by the course and are not redistributed in this repository.
