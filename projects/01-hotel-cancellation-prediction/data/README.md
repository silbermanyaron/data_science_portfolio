# Data

The notebook expects one file in this folder:

- `INNHotelsGroup.csv`: hotel booking records (36,275 rows). Columns include `Booking_ID`, guest counts, weekday and weekend nights, meal plan, parking request, room type, `lead_time`, arrival year, month and date, `market_segment_type`, `repeated_guest`, prior cancellation counts, `avg_price_per_room`, `no_of_special_requests`, and the target `booking_status`.

The dataset was provided by the course and is not redistributed in this repository. The original notebook loaded it under a different filename; rename your copy to `INNHotelsGroup.csv` to run the notebook as is.
